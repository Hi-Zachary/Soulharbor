## 一分钟版（约200–280字）

老师好。我们做的项目叫 SoulHarbor，面向校园心理支持里咨询资源紧、污名压力大的现实，想做一个低门槛的倾听陪伴入口。

核心不是「再做一个聊天机器人」，而是两条线一起做。对话线参考 SoulChat（EMNLP Findings 2023）的倾听叙事：先共情、少急着给建议；我们在 Qwen3-14B 上用 QLoRA 走 PT、SFT、再到 DPO，并让 MacBERT 只在咨询与闲聊上按 0.7 / 0.3 缩放 LoRA，把语气往倾听侧拉。记忆线针对写时抽取容易把短暂情绪冻成错误特质的问题：ER 只存原始 Trace、写入零大模型，查询时再重建；真正进长期 Profile 的，只有白名单事实，比如姓名、教育背景、偏好，没有也可以空着。

同读评测下，对话在 SoulChatCorpus 上 BLEU、ROUGE 相对基线明显抬升；记忆上正式集 `all_50` 问答准确率约 90.5%、陈旧率约 8.6%，明显高于对比的 Mem0（约 68.7% / 46.6%）。样本是五十条可控叙事弧，结论要谨慎，但方向是清楚的：听得更对，记得更稳。

## 三分钟版（约550–700字）

老师好。我介绍一下我们做的 SoulHarbor。先说它从哪里来。校园心理支持里，专业咨询往往稀缺，污名感又强，很多同学不愿意、也约不到正式服务。真正缺的常常不是「再给一条建议」，而是一个低门槛的倾听入口：先被听见，而不是先被教育。我们的目标就落在这里——陪伴式倾听，而不是替代咨询师做临床判断。

这个判断有明确的学术参照。SoulChat 在 EMNLP Findings 2023 里强调：倾听场景里，共情与接住情绪，比过早给建议更重要；而基座模型常常会讲道理，或者给空洞安慰。我们在实践里也碰到两类很典型的失败。一是语气不对齐——该听的时候像在上课，用户一开口就被「你应该怎样」推开。二是记忆写错：如果在写入时就用大模型抽特征、打标签，短暂情绪很容易被冻成「稳定人格特质」，后面越聊越偏，共情也会建立在错误人设上。

所以我们做成双线方案，而不是只改提示词。对话线：在 Qwen3-14B 上用 QLoRA，秩 8、α 为 16，按 PT 到 SFT 再到 DPO 训练；同时用 MacBERT 区分咨询与闲聊，只在这两类上把 LoRA 按 0.7 和 0.3 缩放，把适配力气花在真正需要倾听语气的交互上。记忆线：ER 把原始 Trace 原样入库，写入阶段不调用大模型；需要回忆时再在查询侧重建。长期 Profile 则严格白名单——姓名、教育、偏好这类可核验的长期事实才允许经大模型写入，没有就空着，宁可少记，也不乱贴标签。

证据方面，对话在 SoulChatCorpus 上：BLEU-1 从基线 13.23 到 SFT 的 29.56，DPO 后是 27.91；ROUGE-L 从 15.04 到 24.64，再到 24.44。记忆在同一阅读器 MiniMax 下、正式集 `all_50`（终版多查询 coverage Anchor CE）：ER 问答约 **90.5%**、陈旧率 **8.6%**、F1 **0.783**，对 Mem0 **68.7% / 46.6% / 0.400**。需要坦白的是，记忆评测规模有限，外推要谨慎；但两条线合在一起，回答的是「听得是否对、记得是否稳」这两个核心问题，这也是我们希望老师记住的创新点。

## 十分钟版（约1800–2200字）：背景→问题→对话线方法与动机（引用SoulChat式叙事）→记忆线方法与动机（对比写时抽取/Mem0/MemMachine式宽画像）→证据→边界

老师好。下面我用大约十分钟，把 SoulHarbor 讲清楚：它解决什么问题、为什么这样设计、我们看到了什么证据、以及边界在哪里。整段我会按「背景—问题—对话线—记忆线—证据—边界」来讲，方便老师随时打断追问。

先从背景说起。校园心理健康支持里，有一个很常见的结构矛盾：专业咨询资源相对稀缺，同时污名压力又让很多同学不愿意主动求助。结果是，真正需要被接住的那一段——「有人先听我说」——往往落空。同学卡住的地方，常常不是缺一套标准答案，而是缺一个开口成本足够低的陪伴入口。我们关心的不是替代咨询师，也不是做诊断系统，而是做一个低门槛的倾听入口：降低开口成本，把陪伴放在建议之前，让「先被听见」这件事变得可得。

问题可以收成两句，也对应我们后面的双线。第一句关于对话：基座模型在倾听场景里，很容易变成讲课，或者给空安慰。SoulChat（EMNLP Findings 2023）把这件事说得很清楚——倾听任务里，共情与接住情绪，优先于过早给建议。我们认同这个叙事，而且认为它不只是文风偏好：如果语气一上来就「你应该怎样」，用户会立刻感到不被理解，后续任何记忆再准也难挽回信任。第二句关于记忆：很多系统习惯在写入时就做抽取、打标签、写进画像。短期情绪一旦被写成长期特质，后面的回复就会按错误人设推进，越聊越拧。于是我们看到两类失败：语气不对齐；以及写时记忆抽取把短暂情绪冻成错误特质。这两类失败可以独立出现，但叠在一起时，系统会「听错」又「记错」，危害更大。

解决方案因此是双线，而不是单点技巧，也不是只靠更长的提示词。创新点我们主动收成两句：一是面向倾听域的大模型微调；二是 ER 式长期记忆——原文 Trace、写入零大模型、查询时重建，再配上严白名单 Profile。

先说对话线。动机很直接：把模型从「爱讲道理」拉回「会倾听」。我们在 Qwen3-14B 上做 QLoRA，秩为 8、α 为 16，训练顺序是 PT，再到 SFT，再到 DPO。可以把它理解成三个递进目标：PT 先让模型熟悉倾听域的语言与节奏，减少一开口就像通用助手的疏离感；SFT 再用监督信号学会像样的接话——先回情绪、再澄清、少抢着下结论；DPO 最后用偏好优化，压掉那些听起来正确、但实际上过早说教或空洞安慰的输出。这里我特别想强调 DPO 的位置：它不是训练流水线上的装饰，而是针对 SoulChat 所批评的那类失败模式做偏好侧约束。与此同时，我们用 MacBERT 做场景侧区分，并且只在咨询与闲聊两类上缩放 LoRA，比例分别是 0.7 和 0.3。意思是：并不是所有 token、所有场景都同等用力，而是把适配能力集中在真正需要倾听语气的交互上——咨询侧更强，闲聊侧保留但更克制。这和 SoulChat 式叙事是对齐的：先听、先共情，再谈要不要给建议。

再说记忆线。动机同样明确：反对「写入时就用大模型把人生总结成宽画像」。写时抽取的问题在于，它太急于下结论；短暂的低落、愤怒、自我否定，很容易被固化成稳定标签。宽画像路线——包括我们对照过的 Mem0，以及更偏 MemMachine 式、追求宽覆盖的画像思路——往往在写入侧就做大量语义压缩，追求「什么都记得一点」。在通用助手里这或许可接受，但在倾听场景里，错记的代价常常高于漏记：一个错标签会持续污染后续共情。我们的 ER 反过来做：原始 Trace 入库，写入阶段零大模型调用；真正需要回答「你还记不记得」的时候，再在查询时重建。长期 Profile 则故意做窄：只允许白名单里的长期事实经大模型写入，例如姓名、教育背景、偏好；没有这些事实，Profile 可以空着。空着不是缺陷，而是纪律——宁可少记硬事实，也不把情绪状态误写成人格。换句话说，Trace 负责可回溯的过程材料，Profile 只负责少数可核验的长期事实，两者职责分开，才不容易「把心情写成性格」。

证据方面，我分对话与记忆两条说，数字只保留关键结论。对话评测用 SoulChatCorpus。BLEU-1：基线 13.23，SFT 到 29.56，DPO 后是 27.91；ROUGE-L：15.04，到 24.64，再到 24.44。可以看到，相对基线，SFT 已经把表层匹配明显抬上去，说明倾听向监督微调是有效的；DPO 在这些字面重合指标上未必继续升高，甚至略回落，但它对应的是偏好侧的目标——更少说教、更贴倾听，而不是单纯刷 n-gram。所以如果老师问「为什么 DPO 之后 BLEU 没更高」，我们的回答是：指标目标与训练目标本来就不是同一个东西，DPO 要换的是听感，不是字面重合峰值。记忆评测在同一阅读器 MiniMax 下对比，这一点很重要，因为同读才能把差异主要归因到记忆组织方式：正式集 `all_50` 上 ER 约 **90.5% / 8.6% / 0.783** 对 Mem0 **68.7% / 46.6% / 0.400**。合起来看：对话线证明倾听向微调有效，记忆线证明「原文库加查询时 Anchor CE 重建、Profile 严白名单」比写时宽抽取更抗陈旧、更准。

最后讲边界，也是我们主动要说清楚的，避免把结果讲满。记忆实验是五十条可控叙事弧（30+20），有利于对照，但规模有限，外推要谨慎；可控弧能把「记错特质、记旧信息」这类失败暴露出来，却不能直接外推成大规模真实校园部署结论。我们也不把系统工程、前端或接口当作本项目的创新点来讲；那些可以支撑演示，却不是要向老师主张的贡献。SoulHarbor 想论证的，是两件可口述、可检验的事：在倾听域里，微调能否让语气更对齐；在长期记忆里，把抽取从写入挪到查询、并把画像收成白名单，能否少冻错误特质、少陈旧。如果老师关心下一步，方向也清楚：扩大叙事弧与真实场景覆盖，继续检验 DPO 对「听感」的收益，以及查询时重建策略在更长时程上的稳定性。以上就是十分钟版我想讲完的主线。

### 背景与问题

校园心理健康支持里，专业咨询资源往往不够用，污名又让求助门槛变高。很多同学卡住的地方，并不是「缺一套标准答案」，而是缺一个低门槛的倾听入口：先被听见，再谈要不要进入正式服务。开口本身就需要勇气；如果系统一上来就讲道理、贴标签，或者用错误记忆把人「看死」，第二次就不会再来。我们的项目定位在这里——陪伴式倾听，而不是替代临床决策，也不是做一个什么都管的校园超级助手。

学术上，我们直接对齐 SoulChat（EMNLP Findings 2023）的倾听叙事：共情与接住情绪，优先于过早给建议。这个叙事对我们很重要，因为它把「好回复」从文采或信息量，改写成是否先把情绪接住。现实里基座模型常见两种跑偏：一是讲课式回应，道理很全，情绪落空；二是空洞安慰，听起来温柔，却什么都没接住。这两种失败，用户一听就能感到「不对劲」，但模型自己不一定知道。与此并行，长期记忆也有一条隐蔽的失败路径：如果在写入时就抽取特征、写入宽画像，短暂情绪会被冻成错误特质——比如某一晚的自我否定，变成「用户长期自卑」的标签，后面所有回复都按这个错标签走。更麻烦的是，这种错误会自我强化：系统越「记得清楚」，共情越建立在错人设上。于是项目要同时对付两类失败：语气不对齐，以及写时记忆抽取导致的错误固化。这也是为什么我们不把创新讲成单点：只改语气不够，只改记忆也不够。

### 对话线：方法、阶段动机，以及为何要 DPO

对话线在 Qwen3-14B 上做 QLoRA，秩 8、α 16，顺序是 PT → SFT → DPO；再用 MacBERT 区分场景，并且只在咨询与闲聊上按 0.7 / 0.3 缩放 LoRA。参数上我们不追求花哨，而是把关键选择说清楚：用中等规模可训的大模型做域适配，用低秩适配控制成本，用场景条件化把力气花在倾听相关交互上。

三个训练阶段各自解决不同问题，不能互相替代。PT 解决的是「域语言不熟」：让模型先接触倾听相关的表达方式与节奏，减少一开口就像通用助手的疏离感；它不直接等价于「已经会共情」，但为后面的监督微调准备了更合适的表示空间。SFT 解决的是「会不会接话」：在有监督信号下学习更像倾听的回复结构——先回情绪、再澄清、少抢着下结论；这一步通常能在表层匹配指标上带来最明显的跃升。DPO 解决的是「优选哪一种听感」：同样能回答，仍可能偏说教或偏空安慰；偏好优化用来压这类表面上得体、实际上不贴倾听目标的输出。这也是我们要强调 DPO 的原因——它不是为了在 BLEU 上再刷一截，而是把优化目标从「像参考句」推向「更符合倾听偏好」。如果说 SoulChat 指出了失败模式，DPO 就是我们在训练目标里显式回应这种失败模式的位置：不是事后靠提示词补丁，而是在偏好对上学会「宁可少说教，也要先接住」。

MacBERT 与 LoRA 缩放则是在说：适配预算要花在刀刃上。咨询场景更需要稳定的倾听语气，所以缩放更强，取 0.7；闲聊也需要语气协调，但力度不同，取 0.3。我们刻意不做「全场景一刀切」的适配，而是让咨询与闲聊成为主要作用域。这和 SoulChat 式叙事一致：先把「听」做对，而不是先把「教」做满；同时也避免把域适配均匀摊到并不需要强倾听姿态的内容上。口述时如果老师问「为什么不是端到端只做 SFT」，我们可以答：SFT 解决会不会，DPO 解决更偏好哪一种；场景化 LoRA 则解决力气花在哪里。

### 记忆线：为何原文库加查询时重建，以及 Profile 为何严于宽画像

记忆线上，ER 的核心选择是：原始 Trace 入库，写入零大模型；查询时再重建。为什么要这样？因为写时抽取默认假设「当下就能提炼出稳定事实」。倾听对话里这个假设经常不成立——情绪是状态，不是特质；一次冲突后的措辞，不等于长期信念；用户今天否认自己，明天可能只是在求助过程中的瞬时表达。把抽取前移到写入，等于在信息最不稳定的时候做最强压缩，而且还难以回溯：一旦标签写进画像，后续系统会把它当真相用。原文库保留的是可回溯的材料；查询时重建，则是在「此刻问题需要什么」的条件下再组织，而不是提前写死一个人设。写入零大模型，还有一层方法学上的干净：记忆库首先是证据库，而不是模型意见库。

这也是我们和 Mem0、以及更偏宽画像思路——包括 MemMachine 式追求宽覆盖、提前摘要进画像的路线——的分界。宽画像追求「什么都记得一点」，在通用助手里可能提高表面连贯；但在倾听场景里，错记的代价高于漏记：错把情绪写成特质，会持续污染后续共情，而且用户很难察觉系统到底「记成了什么」。所以 Profile 我们做成白名单：姓名、教育背景、偏好这类可核验、相对长期的事实，才允许经大模型写入；没有就可以空。空 Profile 是合法状态，不是系统没跑起来。严白名单不是功能缺失，而是刻意比宽画像更保守——长期层只承载硬事实，情绪与过程留在 Trace 与查询时重建里。可以把它说成分工：Trace 负责过程与情绪材料的可回溯保存，Profile 负责少数长期事实的谨慎落地；ER 的方法主张，正是拒绝用一次写入时的模型摘要，去替代这两种不同性质的信息。

### 证据、主要消融，以及如何解读数字

对话评测在 SoulChatCorpus 上。BLEU-1：基线 13.23 → SFT 29.56 → DPO 27.91；ROUGE-L：15.04 → 24.64 → 24.44。相对基线，SFT 带来非常清楚的抬升，说明倾听向监督微调有效，模型确实学到了更贴近参考倾听回复的表层形式。DPO 之后字面重合指标略回落，这并不与「DPO 没用」等价：DPO 优化的是偏好，不是 n-gram 重合；结合我们的设计动机，应把它读成「在可接受的表层分数下，换取更贴倾听的偏好」，而不是单纯追 BLEU 峰值。面试里如果被追问「那你怎么证明 DPO 更好」，比较稳妥的说法是：自动字面指标用于显示 SFT 相对基线的有效性；DPO 的主张与 SoulChat 所批评的说教/空安慰相对齐，其收益应结合偏好目标来理解，而不是要求它在 BLEU 上单调递增。

记忆在同一阅读器 MiniMax 下（正式集 `all_50`，终版 coverage CE）：ER 约 **90.5% / 8.6% / 0.783** 对 Mem0 **68.7% / 46.6% / 0.400**。同读设定很重要，它尽量把阅读能力固定，让差异更多来自记忆如何被写入与组织。对老师口述时，把记忆证据收成三句：**更准、更不陈旧、相对 Mem0 差距仍大**。三句都落在已有数字上，不外推。

### 与相关工作的同与异

与 SoulChat：我们同的是倾听叙事——共情优先、警惕过早建议，承认基座模型容易讲课或空安慰；异的是我们把这条叙事落到 Qwen3-14B 的 PT–SFT–DPO 链路，并加上场景条件化的 LoRA 缩放，同时并行做长期记忆约束。SoulChat 主要把问题说清楚并推动倾听向对话；我们在其叙事之上，补了「如何训」和「如何记」两条可操作路径。

与 Mem0 及宽画像式记忆（含更偏 MemMachine 思路的宽覆盖画像）：同的是都关心跨会话一致性，都承认长期记忆对连续陪伴重要；异的是我们拒绝写时强抽取作为默认，改用 Trace 原文库加查询时重建，并把 Profile 收成白名单长期事实。一句话概括同异：对话侧对齐「听」，记忆侧对齐「慢结论、可回溯」；我们不是否定记忆有用，而是反对在最不稳定的时刻做最强压缩。

### 可讲的局限与收束

局限我们主动讲三点，反而更像做研究的人。第一，记忆评测是五十条可控叙事弧（`all_50`），有利于对照，控制变量清楚，但对外泛化要保守表述，不能说成大规模真实部署结论。第二，BLEU、ROUGE 不能单独代表倾听质量；DPO 的收益更应结合偏好目标与听感来理解，字面指标回落不等于失败，也提醒我们后续仍需更贴任务的评价方式。第三，本讲解不把前端、接口或工程栈当作创新主张；SoulHarbor 要被评价的，是域内倾听微调，以及 ER 式长期记忆纪律是否成立。

如果老师问「你最想让人记住什么」，我们可以收成一句双线总结：校园场景需要低门槛倾听；SoulChat 提醒我们先听后建议；我们用双线回应——对话上 PT、SFT、DPO 与场景化 LoRA，把语气往倾听拉；记忆上原文 Trace、查询时重建与严白名单 Profile，把短暂情绪挡在长期特质门外。证据显示，对话匹配相对基线明显提升，记忆准确率与抗陈旧明显优于对照；同时我们承认五十弧样本的边界。这就是 SoulHarbor 想讲清楚的故事：不是更多功能，而是更克制、更可检验的「听得对、记得稳」。口述收束时，不妨再点一次创新焦点——域内倾听微调，以及 ER 长期记忆——其余一概不抢戏。
