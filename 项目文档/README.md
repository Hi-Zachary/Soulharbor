## 建议阅读顺序（保研答辩准备）

1. **01** — 先定口述版本，把「为什么做、两条线、效果数字」说顺。
2. **02** — 补架构图与模块边界，方便白板画系统。
3. **03** — 深挖微调阶段、ER 读写路径、评测协议与结论（面试技术主粮）。
4. **04** — 按题库自问自答；不会的回到 03 对细节。
5. **05** — 演示前扫一遍：怎么启动、记忆开关在哪、管理端看什么、单卡串行等局限怎么答。

时间紧：**01 → 04 高频题 → 05 启动与局限**；架构被追问再翻 02/03。

被问到前端/接口时，可明确说「工程侧见 05，不是研究主线重点」。
