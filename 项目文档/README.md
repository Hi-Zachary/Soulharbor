# SoulHarbor 项目文档

SoulHarbor 是一套校园心理支持对话系统：在开源大模型上完成领域微调与偏好对齐，并配套可开关的长期记忆子系统，辅以可演示的 Web 端。系统已完成训练、评测与端到端联调，适合作为研究原型与演示系统使用；文中指标均来自 `evaluate/*/runs/` 中的真实跑次。

建议先读 `00`，把握「为什么做、怎么做、效果如何」两条主线；再按需要查阅架构、实现、数据与评测附录。
