# 主对话自动评测（SoulChat）

代码、数据与结果均在 `evaluate/dialogue/`。

## 数据与设置

| 数据集 | 路径 | 条数 |
|--------|------|------|
| seen | `evaluate/dialogue/data/soulchat_seen_1k.jsonl` | 1000 |
| unseen | `evaluate/dialogue/data/soulchat_unseen_1k.jsonl` | 1000 |

- 指标：BLEU-1/2/3/4、ROUGE-1/2/L（`evaluate/dialogue/lib/metric.py`，jieba 分词后计算）
- 已跑结果：`evaluate/dialogue/runs/soulchat_corpus_eval_20260426_092741/`
- 对比模型：`base`（裸 Qwen3-14B）、`sft`（目录名 `self_cognition`）、`dpo`（线上 chat LoRA）

## 综合方式（正确）

**每个模型单独算**：对该模型在 seen、unseen 上的指标，按预测条数加权平均（各 1000 → 等价算术平均）。  
得到 **3 组**结果（base / sft / dpo），而不是把三个模型混在一起。

JSON：`evaluate/dialogue/runs/soulchat_corpus_eval_20260426_092741/aggregate_per_model_seen_unseen.json`
