## SoulHarbor：SoulChat 4B3R 自动评测启动（双卡并行）

评测内容：两组数据（seen/unseen 各 1k）× 三个模型（`base+dpo -> base -> base+self_cognition`）× 指标（BLEU-1/2/3/4 + ROUGE-1/2/L）。

### 1) 建议在 `screen` 里启动

```bash
screen -S soulchat_eval
```

### 2) 启动命令（双卡并行 + 自动 batch 回退 + 关 think）

```bash
cd /root/autodl-tmp/SoulHarbor

# 双卡并行：seen 用 cuda:0，unseen 用 cuda:1
# BATCH_SIZE_START=32：先用大 batch 尝试，若 OOM 会自动 32->16->8->4->2->1，并用 --resume 续跑
# enable_thinking 默认关闭（ENABLE_THINKING=0），不会在 predictions 里出现 <think>...

PARALLEL=1 \
DEVICE_SEEN=cuda:0 \
DEVICE_UNSEEN=cuda:1 \
FAST_STOP=1 \
LIMIT=0 \
BATCH_SIZE_START=32 \
MAX_INPUT_LEN=1536 \
MAX_NEW_TOKENS=512 \
DO_SAMPLE=1 \
TOP_P=0.75 \
TEMPERATURE=0.95 \
REPETITION_PENALTY=1.0 \
LOAD_IN_4BIT=1 \
ENABLE_THINKING=0 \
bash evaluate/dialogue/run_soulchat_eval_pipeline.sh
```

运行开始后会输出本次 run 目录，例如：
`evaluate/dialogue/runs/soulchat_corpus_eval_YYYYMMDD_HHMMSS`

### 3) 退出并保留后台运行

```bash
# 退出 screen（不停止任务）
Ctrl+A  D
```

### 4) 查看进度（日志/行数）

把下面的 `<RUN_DIR>` 替换为实际目录名（例如 `soulchat_corpus_eval_20260426_090849`）。

```bash
cd /root/autodl-tmp/SoulHarbor

# 看总控日志（包含 pid、并行配置、最终 summary 路径等）
tail -f evaluate/dialogue/runs/<RUN_DIR>/pipeline.log

# 看两张卡各自的详细日志（含 [PROGRESS] done/1000 rate/eta）
tail -f evaluate/dialogue/runs/<RUN_DIR>/seen.log
tail -f evaluate/dialogue/runs/<RUN_DIR>/unseen.log

# 看每个子任务 predictions 写出到第几行（最终每个应为 1000）
watch -n 30 'for d in base_seen base_unseen self_cognition_seen self_cognition_unseen dpo_seen dpo_unseen; do echo -n \"$d: \"; wc -l evaluate/dialogue/runs/<RUN_DIR>/$d/predictions.jsonl 2>/dev/null || echo 0; done'
```

### 5) 结果位置

```bash
cd /root/autodl-tmp/SoulHarbor
cat evaluate/dialogue/runs/<RUN_DIR>/summary.md
```

### 6) 停止评测（如需）

```bash
ps -ef | grep -E "run_soulchat_eval_pipeline.sh|run_soulchat_paper_eval.py" | grep -v grep
ps -ef | grep -E "run_soulchat_eval_pipeline.sh|run_soulchat_paper_eval.py" | grep -v grep | awk '{print $2}' | xargs -r kill -9
```
